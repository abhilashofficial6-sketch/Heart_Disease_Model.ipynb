 Heart Disease Prediction 

About Our Project

For our project, we chose to work with the Heart Disease dataset from the UCI Machine Learning Repository.

We selected this dataset because heart disease is an important health issue, and we wanted to see how Python and machine learning can be used to understand health-related data.

The main idea behind our project is to look at different patient health measurements and see whether we can identify patterns related to heart disease.

We are using Google Colab to write and run our Python code. Throughout this project, we are learning how to prepare a dataset, explore the information, create graphs, and build machine learning models.

Our goal is not to create a medical diagnosis system. We want to understand how machine learning works with real-world healthcare data and what we can learn from the results.

Dataset We Selected

We are using the Cleveland Heart Disease dataset, which is available through the UCI Machine Learning Repository.

Dataset Source

https://archive.ics.uci.edu/dataset/45/heart+disease

Dataset Used in Google Colab:

https://archive.ics.uci.edu/ml/machine-learning-databases/heart-disease/processed.cleveland.data

The original dataset contains 303 patient records with information such as:

- Age
- Sex
- Chest pain type
- Blood pressure
- Cholesterol level
- Maximum heart rate
- Other health-related measurements

The dataset also includes information about whether heart disease was recorded for a patient.

For our analysis, we converted this information into two categories: patients with recorded heart disease and patients without recorded heart disease.
